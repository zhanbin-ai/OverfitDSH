# @deepseek-ai/dsh-client-ui-git

[English](README.md) | 中文

## 概述

本包让你在右侧栏直接处理会话工作区所在的仓库：注册 `git` 标签类型、引导入口与工作台正文。正文列出已暂存与已变更的路径，点击任一行打开其统一差异，可单路径暂存/取消暂存（也可一键全部暂存），按需展开最近历史，并用你写的消息提交暂存区。所有调用都走 `git` 远程命名空间（`@deepseek-ai/dsh-api-git`）；正文不持有宿主状态，注入的 face 绑定单一会话 id。

## 使用本包

挂载本包后从右侧栏打开 Git 标签（该标签类型同时提供引导入口），随后：

| 控件 | 行为 |
|---|---|
| 分支胶囊 | 会话工作区仓库的当前分支，游离 HEAD 时显示提示 |
| 变更列表 | 工作区变更；点击行打开其未暂存差异；行内操作暂存该路径；「全部暂存」一次暂存所有 |
| 已暂存列表 | 暂存区变更；点击行打开其已暂存差异；行内操作取消暂存该路径 |
| 历史 | 最近提交，最新在前，首次展开时加载 |
| 提交框 | 消息 + 「提交」按钮：提交暂存区并刷新快照 |

工作区不在仓库内时，失败横幅会显示 `git/not-repository`；尚无提交的仓库，历史为空列表。

## 理解实现

标签的异步半部在 `face.ts`：把 `git` 命名空间绑定到 Slot 框架解析出的会话，交给组件一组返回结果的普通函数。组件本地持有状态；每个写操作都以新的 `status` 快照作答，列表与提交框从不猜测——失败统一落进横幅而非 toast。样式为 CSS Modules + `--dsw-*` token，状态字母按类别着色。

## 已知限制与延期工作

- **没有文件监视**——刷新靠显式控件与操作后快照；回合结束自动刷新属延期项。
- **没有块级暂存**——暂存以路径为单位；分栏视图、块选择与分支操作属延期项。
- **尚无 AI 提交信息**——「生成提交信息」随 LLM 接线在后续增量交付。
- **差异大小**——单次差异受宿主配置上限（默认 256 KiB）；被截断的差异会在面板中标注。
